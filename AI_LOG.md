# Лог работы с AI

Инструмент: Claude (Anthropic), веб-чат. Ниже — ход работы и ключевые решения.

## Запрос
Приложен файл ТЗ «Тестовое задание: сервис форм» с просьбой выполнить задание.

## Ход работы
1. **Анализ ТЗ.** Ключевые требования: `npm install` + `npm start`, порт из `PORT`, без внешних зависимостей/СУБД, `/admin` без авторизации, публичная форма по сгенерированной ссылке. Из «Проблемы» выделил две боли: (а) менеджер зависит от разработчиков → конструктор форм; (б) неизвестна причина отказов → аналитика воронки.
2. **Выбор стека.** Только встроенные модули Node.js 20+ (без Express и SQLite): сборка нативных модулей и скачивание пакетов — лишний риск для «запуск строго по инструкции». Хранилище — JSON-файл с атомарной записью.
3. **Реализация:** сервер + API → публичная форма → админка → README.
4. **Проверка.** Написан сквозной тест `test/smoke.js` (создание формы, публикация, валидация, отправка, статистика, CSV, удаление, path traversal). Выполнен реальный запуск `npm install && PORT=… npm start`.
5. **Что не проверено автоматически:** визуальная часть интерфейса в браузере (в среде разработки не было браузера) — клиентский код проверен только чтением и проверкой синтаксиса. Рекомендуется прокликать вручную.
